# Prompts to Recreate the IPO Tracker Application

This document provides a series of prompts to guide a large language model in recreating the IPO Tracker application. The prompts are structured to build the application in logical, incremental steps.

---

### Prompt 1: Create the Basic IPO Tracker UI and Data Fetching

**Objective:** Build the main application window, fetch IPO data from IPO Scoop, and display it in a basic table.

**Prompt:**
"Create a Python application using Tkinter that tracks upcoming IPOs. The application should have a main window with a Treeview widget to display the IPO data.

1.  **Data Fetching:** Implement a function to fetch the IPO calendar from 'https://www.iposcoop.com/ipo-calendar/'. Use the `requests` library for HTTP requests and `BeautifulSoup` for parsing the HTML. If `BeautifulSoup` is not available, include a fallback mechanism that uses regular expressions to parse the table.
2.  **Data Model:** Define a dataclass named `IPO` to store the information for each company, including: Company, Symbol, Lead Managers, Shares, Price Range, Est. Volume, and Expected Trade Date.
3.  **UI:**
    *   Create a main window using `tkinter.Tk`.
    *   Add a `ttk.Treeview` to display the list of IPOs. The columns should correspond to the fields in the `IPO` dataclass.
    *   Add a "Refresh" button that, when clicked, fetches the latest IPO data and populates the Treeview.
    *   Display a status bar at the bottom to show the current state (e.g., "Fetching data...", "Data loaded").
4.  **Execution:** The application should fetch data immediately upon launching."

---

### Prompt 2: Add Sorting, Filtering, and Searching

**Objective:** Enhance the UI with controls for sorting the data, filtering by category, and searching.

**Prompt:**
"Now, enhance the IPO Tracker application with sorting, filtering, and search capabilities.

1.  **Sorting:**
    *   Make the Treeview column headers clickable.
    *   When a header is clicked, sort the data in the table by that column. Clicking the same header again should reverse the sort order.
2.  **Categorization:**
    *   Implement a simple function to categorize each IPO based on keywords found in its company name (e.g., "Financial", "Pharmaceutical", "AI").
    *   Add a "Category" column to the Treeview.
    *   Add a `ttk.Combobox` widget above the table to filter the displayed IPOs by the detected category. Include an "All" option.
3.  **Searching:**
    *   Add a `ttk.Entry` widget as a search bar.
    *   As the user types in the search bar, dynamically filter the table to show only the rows that contain the search term in any of their columns."

---

### Prompt 3: Implement the Notification System

**Objective:** Add the core logic for scheduling and managing local notifications for IPOs.

**Prompt:**
"Integrate a local notification system into the IPO Tracker.

1.  **Notification Scheduler:**
    *   Create a `NotificationScheduler` class that runs in a background thread to manage and trigger notifications.
    *   The scheduler should be able to schedule notifications for a specific IPO at predefined times (e.g., 24 hours and 3 hours before the trade date).
    *   Implement functions to `schedule_ipo_notification` and `remove_ipo_notification`.
2.  **Persistence:**
    *   The scheduler should save its state (the list of scheduled notifications) to a JSON file (`ipo_notifications.json`) in a user-specific application data directory.
    *   When the application starts, it should load this file to restore any pending notifications.
3.  **UI Integration:**
    *   Add a "🔔" (bell) column to the far left of the Treeview.
    *   When the user clicks on a cell in this column, it should toggle a notification for that IPO. A "✓" should appear if a notification is active.
    *   When a notification is toggled on, use the `NotificationScheduler` to schedule it. When toggled off, remove it."

---

### Prompt 4: Advanced Notification Configuration and Display

**Objective:** Create a dialog for detailed notification settings and a panel to display all scheduled notifications.

**Prompt:**
"Improve the notification system with more detailed controls and better visibility.

1.  **Configuration Dialog:**
    *   When a user double-clicks any row in the table, open a `NotificationDialog`.
    *   This dialog should display details about the selected IPO and provide checkboxes to let the user choose which specific reminders they want (e.g., "Notify 1 day before at 8:00 AM", "Notify same day at 8:00 AM").
    *   Add a "Save" button in the dialog to apply the settings.
2.  **Scheduled Notifications Panel:**
    *   Add a text widget at the bottom of the main window.
    *   This panel should display a list of all currently scheduled notifications, showing the IPO ticker and the exact time the notification is due.
    *   This panel should refresh periodically to stay up-to-date.
3.  **Bulk Setup:**
    *   Add a "Setup Notifications" button that allows the user to apply notification settings to all selected rows in the table at once."

---

### Prompt 5: Implement Save/Load Choices and Company Analysis

**Objective:** Add functionality to save and load user selections and create the company analysis window.

**Prompt:**
"Add features for saving and loading user choices and for in-depth company analysis.

1.  **Save/Load Choices:**
    *   Add "Save Choices" and "Load Choices" buttons.
    *   "Save Choices" should save the notification settings for all currently marked IPOs into a file named `ipo_choices.json`.
    *   "Load Choices" should read this file and re-apply the saved notification settings to the corresponding IPOs in the current list.
2.  **Company Analysis Window:**
    *   Add a "🔍" (magnifying glass) icon column next to the notification column.
    *   When a user clicks this icon, open a new `CompanyAnalysisDialog` window.
    *   This dialog should display:
        *   The company name and symbol.
        *   A list of clickable links for further research (e.g., Official Website, Wikipedia, Yahoo Finance, SEC EDGAR).
        *   A section for recent articles and buzz, fetched from a search engine like DuckDuckGo.
    *   **Crucially, ensure that if the application is running as a compiled executable (e.g., via PyInstaller), it does not attempt to dynamically install any missing packages like `tkinterweb`. This can be checked using `getattr(sys, 'frozen', False)`. This prevents the app from re-launching itself.**"

---

### Prompt 6: Final Touches and Instructions

**Objective:** Add an instructions guide, a test notification button, and ensure the application is polished and user-friendly.

**Prompt:**
"Finalize the IPO Tracker application with instructions, testing tools, and other usability improvements.

1.  **Instructions Window:**
    *   Add an "Instructions" button that opens a new window containing a detailed guide on how to use the application, explaining all features like sorting, filtering, notifications, and saving/loading.
2.  **Test Notification:**
    *   Add a "Test Notify Now" button that triggers a sample notification immediately, allowing users to check if the notification system is working correctly on their OS.
3.  **In-App Notification Display:**
    *   When a notification is triggered, instead of only relying on the OS, display a custom pop-up window within the application itself. This window should show the IPO details and have an "OK" button to dismiss.
4.  **Code Cleanup and Docstrings:**
    *   Review the entire script. Add clear docstrings and comments where necessary.
    *   Ensure all functions and classes are well-defined and the code is organized logically.
    *   Make sure the date parsing logic is robust and can handle various formats (e.g., 'MM/DD/YYYY', 'Month DD', 'Week of...')."
